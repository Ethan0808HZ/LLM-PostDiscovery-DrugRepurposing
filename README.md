# LLM-PostDiscovery-DrugRepurposing
Prompts, intermediate outputs, and results for an LLM-based post-discovery framework for drug repurposing prioritization and mechanism validation

In the paper, we mapped three final verdict from HYPOTHESIS_HOLDS_UP, INCONCLUSIVE, HYPOTHESIS_UNDERMINED to Strong Hypothesis, Moderate Hypothesis, and Weak Hypothesis.  

Deep Validation was conducted in two sequential batches using the same prompt. The first batch evaluated PMX205 and Oltipraz. The second batch evaluated Neflamapimod, Emricasan, ANX005, and Bis-T-23.
